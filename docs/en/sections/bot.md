# Managing your Telegram bot

Configure menus, greetings, images, documents, tickets, referrals and buttons without changing code.

**Where to find it:** `#/bot` — Sales.

## Workflow

1. Set the bot token in the service environment.
2. check the bot.
3. configure text and links.
4. save.
5. open /start.

## Mini App and team group

Install the customer website first, then select its working installation for Mini App. Mini App is unavailable without it. Configure menu order, purchases and add-ons. For team alerts, add the bot to a group, run /chatid in the intended topic, save group/topic IDs and categories, then send a test.

## Verify the result

Settings may take up to 30 seconds to refresh. For mandatory channel membership, the bot must be a channel administrator. The customer website is installed separately.
