# Discounts and bonus days

A percentage reduces the price, a fixed discount uses the project currency, and a bonus adds days after payment.

**Where to find it:** `#/promos` — Sales.

## Workflow

Set the code, effect, use limit and expiry, and optionally a plan or first-purchase restriction. Test it in the bot before publication.

## Checking restrictions

Use a test customer to check eligible plans, expiry and usage limits. Test a first-purchase discount with a customer who has no earlier successful payment. When restrictions do not match, the code must not alter the invoice amount.

## Verify the result

An abandoned invoice must not consume a use. An exhausted or expired code does not work even if enabled.
