# Configuration profiles

Open `#/profiles` under Infrastructure. A profile stores the entire server JSON and can be assigned to multiple nodes.

## Workflow

New profile offers a ready-made scenario, JSON import or a blank profile. Complete parameters, generate missing keys, validate JSON and create the profile. Save your configurations in a separate template library with RU/EN descriptions.

Before changing a working profile, review affected nodes, hosts and squads. Rehearse on a free test node, then apply the verified configuration to the production profile. Deployment status shows the agent's version acknowledgement. History can load an older configuration into the draft.
