# Access groups

A squad groups inbounds. Plans assign squads to customers, and these determine the available locations.

**Where to find it:** `#/squads-int` — Infrastructure.

## Workflow

Create a group, select its inbounds and assign it to a plan or customer. Check a subscription using that plan.

## Free and Premium example

Free contains basic inbounds; Premium contains additional ones. Assign both squads for combined access, or include the basic inbounds in Premium. Use Available nodes to inspect the resulting links. Bulk membership actions affect all selected customers; use customer records for individual changes.

## Verify the result

The inbound must run on a live node and have an enabled host. Squad membership alone does not create a server or open a port.
