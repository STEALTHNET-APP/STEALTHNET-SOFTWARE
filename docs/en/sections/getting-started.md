# First setup

Follow the steps to configure your own service.

**Where to find it:** `#/getting-started` — Start here.

## Workflow

Work from top to bottom. A green check means the corresponding data exists in the panel.

## End-to-end trial

After setup, buy a test plan, check payment status and subscription expiry, import the configuration, connect and verify the external IP and traffic usage. Disable the test customer and verify access stops. Separately test code sign-in and Telegram linking.

## Verify the result

The final step is required: connect a test customer and verify that access stops after disabling it.
