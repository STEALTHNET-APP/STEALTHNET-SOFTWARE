# How your service works

The panel manages access, the bot sells plans, the server agent handles connections, and the subscription service delivers client configurations.

**Where to find it:** `#/home` — Start here.

## Workflow

Start with the setup guide. After creating a test subscription, connect to the VPN and check that traffic usage increases.

## Checking the overview

Compare the selected period, currency and metric freshness. Open a stale node to inspect its latest report. An online indicator and a successful VPN connection are separate checks. Revenue can be zero before the first payment.

## Verify the result

Revenue is not profit. Server costs are tracked separately; amounts in different currencies cannot be added without conversion.
