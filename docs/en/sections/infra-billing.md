# Server costs

Planned node costs, providers and recorded payments help track service expenses.

**Where to find it:** `#/infra-billing` — Hosting costs.

## Workflow

1. Add a provider.
2. set the node cost and due day.
3. record actual payments.

## Overdue hosting payment

Check the due date, currency and actual hosting transfer. Record the payment after paying. A reminder does not replace the provider invoice or perform an automatic charge.

## Verify the result

This tracks costs; it does not pay hosting invoices. Review amounts after changing currency. Fees and other expenses are not added automatically.
