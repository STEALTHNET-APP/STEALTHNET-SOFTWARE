# Traffic history

The table shows transferred traffic by node for the selected period. An empty day means no counters were recorded.

**Where to find it:** `#/nodes-stats` — Infrastructure.

## Workflow

Choose a period and compare changes with customer connections, server maintenance and customer limits.

## Comparing history

Use the same period for all nodes. Check the time zone and days without reports. History contains received counters, so account for agent downtime separately. Resetting history does not repair a network problem.

## Verify the result

Resetting node statistics deletes its traffic history. Historical totals do not describe current load or connection speed.
