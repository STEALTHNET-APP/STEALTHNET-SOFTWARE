# Subscription request history

See when a link was refreshed, which app requested it, the chosen format and the IP when available.

**Where to find it:** `#/srh-inspector` — Tools.

## Workflow

Search for a short ID, User-Agent or IP. Compare the format with response rules. Revoke a leaked link from the customer record.

## Wrong subscription format

Compare User-Agent, selected format and response rules. If a link leaked, revoke access in the customer record and help import the replacement subscription. Do not publish full subscription links from history in public issues.

## Verify the result

Frequent requests may be normal automatic refreshes. A subscription request alone does not prove a VPN connection.
