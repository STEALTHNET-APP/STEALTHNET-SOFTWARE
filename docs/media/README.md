# Interface gallery / Галерея интерфейса

[English project page](../../README.md) · [Русская страница проекта](../../README.ru.md)

These captures use the actual application UI in an isolated development environment. Example network names, addresses, measurements and plan labels are demonstration data, not production metrics or availability claims. No customer access code or service credential is displayed. Mini App captures use the actual /app/ interface with the Telegram bridge supplied by the local test harness; native Telegram chrome is not included.

Снимки показывают настоящий интерфейс проекта в изолированном окружении. Имена, адреса, показатели сети и названия тарифов — демонстрационные данные, а не статистика рабочего сервиса. Коды доступа и служебные секреты не показаны. Снимки Mini App сделаны с настоящего интерфейса /app/ с тестовым мостом Telegram; нативное окно Telegram в кадр не входит.
