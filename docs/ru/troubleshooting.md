# Диагностика

Начинайте с конкретной неработающей операции и времени ошибки. Не публикуйте .env, токены, код доступа и полную ссылку подписки.

| Симптом | Проверить |
|---|---|
| Панель не открывается | DNS, 80/443, Caddy, `systemctl status sn-api`, `stealthnet doctor` |
| API работает, база нет | PostgreSQL, DATABASE_URL, журналы API, свободный диск |
| Сервис подписок не отвечает | Локальный и публичный `/ready`, sn-sub, его режим db/api и служебный ключ |
| Нода на связи, VPN нет | Статус Xray, профиль, активный инбаунд, порт, хост и внутренний сквад |
| Клиент не видит локацию | Срок/статус/трафик, сквад, активная нода, включённый хост, исключения форматов |
| Нет докупок | Пакеты именно текущего тарифа, допустимость подписки, покупки кабинета и кнопка бота |
| Оплата ожидает | Статус провайдера, callback HTTPS, сумма/валюта и внешний ID |
| Mini App недоступно | Установленный кабинет, выбранная установка, `/ready`, ключ и настройки бота |
| Копирование не сработало | HTTPS и разрешение буфера; интерфейс должен показывать результат или ошибку |
| EN-текста нет | Переключатель языка, поля English бренда и соответствующего тарифа |
| Нет обновлений | Есть ли стабильный Release, оба архива и SHA256; состояние проверки GitHub |

## Что приложить к сообщению об ошибке

Версия панели и Xray, ОС/архитектура, раздел, шаги воспроизведения, ожидаемый и фактический результат, время с часовым поясом, обезличенный фрагмент журнала. Для визуального бага — размер окна, язык, тема и скриншот без персональных данных. Для уязвимостей используйте [порядок приватного сообщения](../../SECURITY.md).

Проверка API, выдачи подписки и VPN-соединения — три разных проверки. После исправления повторите исходный сценарий и ближайший связанный: например, после оплаты проверьте и срок, и подключение.
