# Поддержка

Обращения из бота связаны с клиентской карточкой. Ответ из панели отправляется клиенту в Telegram.

**Где открыть:** `#/support` — Клиенты.

## Порядок работы

1. Откройте обращение.
2. прочитайте переписку и статус подписки.
3. ответьте.
4. закройте после решения.

## Если ответ не дошёл

Проверьте получателя и состояние бота. Клиент должен разрешать сообщения боту. Закрытый тикет сохраняет переписку; повторное открытие не создаёт второй клиентский аккаунт. В уведомления команды не пересылается полная переписка.

## Проверка результата

Закрытие не удаляет историю. Если ответ не доставлен, проверьте доступность бота и не заблокировал ли его клиент.
