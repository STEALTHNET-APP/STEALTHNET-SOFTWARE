# Happ routing

Профиль передаётся вместе с подпиской через заголовок routing. Он задаёт направления VPN, напрямую и блокировку, а также DNS.

**Где открыть:** `#/happ-routing` — Подписка.

## Порядок работы

1. Откройте конструктор.
2. заполните списки доменов и IP.
3. проверьте приоритет и DNS.
4. используйте профиль.
5. обновите подписку в Happ и переподключитесь.

## Проверка маршрутов

Проверьте один домен каждого типа: VPN, напрямую и блокировка. После изменения обновите подписку и переподключитесь. Для сложного JSON проверьте сохранение дополнительных полей и размер ссылки; длинные списки удобнее выражать через geosite/geoip.

## Проверка результата

JSON и импорт сохраняют расширенные поля. Ограничение ссылки — 8 КБ; для больших списков используйте geosite/geoip. Обработка профиля зависит от версии Happ.
