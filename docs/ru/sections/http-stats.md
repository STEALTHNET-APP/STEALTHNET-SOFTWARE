# HTTP-статистика

Опциональная статистика обращений клиентов. По умолчанию выключена.

**Где открыть:** `#/http-stats` — Инструменты.

## Порядок работы

При необходимости включите сбор, задайте срок хранения и проверьте появление новых записей.

## Сбор и хранение

Задайте необходимый срок хранения и проверьте очистку воркером. Если данные не поступают, проверьте поддержку на ноде и включение сбора. Выключение не является мгновенным удалением всей ранее накопленной истории.

## Проверка результата

Это чувствительная история активности. Включайте только осознанно; отключение прекращает новые записи, срок хранения удаляет старые.
