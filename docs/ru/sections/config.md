# Редактор конфига

Готовые профили и блоки маршрутизации помогают собрать конфигурацию без переписывания всего JSON.

**Где открыть:** `#/config` — Инфраструктура.

## Порядок работы

1. Выберите заготовку.
2. заполните параметры.
3. отформатируйте.
4. запустите проверку.
5. сохраните.
6. проверьте состояние движка на ноде.

## Ошибки проверки

Проверьте JSON, уникальные теги инбаундов, порты и ссылки маршрутов на существующие outboundTag. После вставки готового блока проверьте весь документ. Структурная проверка дополняется xray -test только при наличии бинарника Xray в среде API; её статус нельзя считать проверкой каждого сервера.

## Проверка результата

Порядок правил маршрутизации важен: срабатывает первое подходящее. Приватные ключи и пароли не публикуйте. Успешная проверка синтаксиса не заменяет реальное подключение.
