# Статистика нод

Таблица показывает объём передачи по нодам за выбранный период. Пустой день означает отсутствие сохранённых счётчиков.

**Где открыть:** `#/nodes-stats` — Инфраструктура.

## Порядок работы

Выберите период и сопоставьте изменения с подключениями, работами на серверах и лимитами клиентов.

## Сверка истории

Используйте одинаковый период при сравнении нод. Проверьте часовой пояс и дни без отчётов. История содержит полученные счётчики, поэтому простои агента нужно учитывать отдельно. Сброс истории не исправляет сетевую неисправность.

## Проверка результата

Сброс статистики ноды удаляет историю её трафика. История не заменяет текущую нагрузку и не является замером скорости.
