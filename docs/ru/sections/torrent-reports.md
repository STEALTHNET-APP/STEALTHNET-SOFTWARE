# Торрент-репорты

Агент собирает счётчики отклонённых соединений из журнала Xray.

**Где открыть:** `#/torrent-reports` — Инструменты.

## Порядок работы

Выберите период и откройте клиента, чтобы разобраться в повторных срабатываниях. Проверьте правила маршрутизации профиля.

## Проверка причины блокировки

Сравните время события с правилами routing профиля и журналом движка. Одинаковое правило BLOCK может обслуживать разные категории. Перед изменением блокировки проверьте, какие ноды используют профиль.

## Проверка результата

Цель блокировки сама по себе не доказывает скачивание торрента. Одно правило block может использоваться для нескольких категорий трафика.
