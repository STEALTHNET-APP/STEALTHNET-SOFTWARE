# Шаблоны подписки

Шаблон задаёт обёртку ответа, а серверы формируются системой с ключами текущего клиента.

**Где открыть:** `#/templates` — Подписка.

## Порядок работы

1. Выберите формат.
2. создайте шаблон из готового пресета.
3. проверьте результат на примерных серверах.
4. назначьте по умолчанию или в правиле ответа. В редакторе есть справка по меткам.

## Порядок выбора

Для каждого формата хранится свой шаблон по умолчанию. Правило ответа может выбрать конкретный шаблон; далее учитываются назначения внешнего сквада и хоста. В редакторе используйте справку по подстановкам и предпросмотр с тестовым клиентом. Серверы и секреты пользователя подставляет система.

## Проверка результата

Не вставляйте чужие ключи и адреса клиентов в общий шаблон. Формально валидный JSON может не подходить конкретному VPN-приложению.
