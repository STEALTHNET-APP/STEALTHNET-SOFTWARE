# Внешние сквады

Внешний сквад меняет шаблоны, роутинг, заголовки и параметры хостов для участников. У клиента может быть один внешний сквад; доступ к нодам дают внутренние сквады.

**Где открыть:** `#/squads-ext` — Инфраструктура.

## Порядок работы

1. Создайте сквад.
2. задайте нужные переопределения.
3. назначьте его в карточке клиента. Правило ответа выше шаблона внешнего сквада, затем применяется шаблон хоста или Default.

## Наследование настроек

У клиента допускается один внешний сквад. Выберите отдельный шаблон каждого нужного формата, затем настройки подписки и хостов. Параметры хоста из сквада применяются ко всем получаемым хостам. Явное пустое значение отличается от отсутствующего переопределения. Проверьте результат в нескольких клиентских приложениях, особенно если настроены правила ответов.

## Проверка результата

Пустой текст и выключенный переключатель — явные значения. Снятие галочки отменяет переопределение. Без активного внешнего сквада используются глобальные настройки. Экспорт хостов партнёру доступен отдельно в меню сквада.
