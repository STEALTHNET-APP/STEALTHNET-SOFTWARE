# Телеграм-бот

Меню, приветствие, изображения, документы, обращения, реферальная программа и кнопки настраиваются без правки кода.

**Где открыть:** `#/bot` — Продажи.

## Порядок работы

1. Установите токен бота в окружении сервиса.
2. нажмите «Проверить бота».
3. настройте тексты и ссылки.
4. сохраните.
5. откройте /start.

## Mini App и рабочая группа

Сначала установите кабинет, затем выберите его работающую установку для Mini App. Без кабинета Mini App недоступно. Настройте порядок кнопок, покупки и докупки в меню. Для уведомлений добавьте бота в группу, выполните /chatid в нужной теме, сохраните ID группы/темы и категории, затем отправьте тест.

## Проверка результата

Настройки подхватываются с задержкой до 30 секунд. Для обязательной подписки на канал бот должен быть его администратором. Отдельный веб-кабинет — другой компонент.
