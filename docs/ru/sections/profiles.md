# Профили конфигураций

Откройте `#/profiles` в разделе «Инфраструктура». Профиль хранит полный серверный JSON и может быть назначен нескольким нодам.

## Порядок работы

«Новый профиль» предлагает готовый сценарий, импорт JSON или пустой профиль. Заполните параметры, сгенерируйте недостающие ключи, проверьте JSON и создайте профиль. Свои конфигурации можно сохранить в отдельную библиотеку шаблонов с описаниями RU/EN.

При изменении рабочего профиля просмотрите затронутые ноды, хосты и сквады. Для проверки выберите свободную тестовую ноду; затем примените проверенную конфигурацию к рабочему профилю. Статус показывает подтверждение версии от агента. История позволяет вернуть старую конфигурацию в черновик.
