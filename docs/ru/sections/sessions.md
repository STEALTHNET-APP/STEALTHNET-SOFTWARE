# Кто сейчас в сети

Онлайн определяется по недавней передаче данных, а не по списку открытых сетевых соединений.

**Где открыть:** `#/sessions` — Инструменты.

## Порядок работы

Обновите список, выберите клиента и при необходимости откройте его карточку.

## Как читать статус

Отсутствие недавнего трафика не обязательно означает закрытое приложение. Для прекращения доступа отключите клиента, дождитесь синхронизации нод и проверьте соединение. Для проблемы конкретного сервера перейдите в его карточку.

## Проверка результата

Здесь нет кнопки разрыва отдельного TCP-соединения. Для прекращения доступа отключите клиента и проверьте синхронизацию ноды.
