# Профиль администратора

[Русский / English](../../en/sections/admin-profile.md)

Откройте меню аккаунта внизу боковой панели → **Профиль администратора** (`#/admin-profile`). Здесь находятся ваши контактные данные, смена пароля, TOTP, passkeys и завершение остальных сессий.

Подробная инструкция: [первый вход, личный профиль и команда](team.md).
