# Хосты

Хост — опубликованная локация: имя, адрес, порт и привязка к инбаунду профиля. Нода — машина, на которой этот инбаунд работает.

**Где открыть:** `#/hosts` — Инфраструктура.

## Порядок работы

Сначала создайте профиль и подключите ноду. Затем добавьте хост, выберите инбаунд, укажите доступный снаружи адрес и порт. Включите хост.

## Проверка опубликованной локации

Адрес и порт должны быть доступны клиенту, а не только панели. Сопоставьте инбаунд хоста с активными инбаундами ноды и сквада клиента. Xray JSON-параметры Mux, SockOpt и другие расширения применяются только к соответствующим форматам. Исключение формата подписки может скрыть хост в одном приложении и оставить в другом.

## Проверка результата

Ключи Reality берутся из профиля. После замены инбаунда проверьте привязки хостов. Выключение хоста скрывает локацию из выдачи, но не равнозначно остановке порта на сервере.
