# Платёжки и валюты

Модуль создаёт счёт и подтверждает оплату. Доступны Stars, CryptoBot, ручная оплата и настраиваемый HTTP-модуль.

**Где открыть:** `#/providers` — Продажи.

## Порядок работы

1. Выберите валюту сервиса.
2. настройте ключи модуля.
3. включите нужные валюты.
4. задайте цены тарифов.
5. выполните тестовую покупку.

## Настройка провайдеров

На новой установке модуль **«Вручную» включён по умолчанию** для всех валют панели: USD, EUR, RUB, UAH, KZT, TRY и GBP. Ключи не нужны: клиент получает инструкцию для связи с поддержкой, а администратор подтверждает поступление денег в разделе «Платежи». При желании отключите модуль или отдельные валюты — этот выбор сохраняется при обновлении. Ранее сохранённые настройки существующей установки не сбрасываются.

В `.env` пустой или отсутствующий `PAY_MANUAL_CURRENCIES` означает все перечисленные валюты. Если там остался явный список, например `USD,RUB`, он продолжает ограничивать модуль. Telegram Stars настраиваются отдельно.

Для Platega нужны Merchant ID и secret; для RollyPay — API key и signing secret; для ParityPay v2 — Shop ID и два секрета. Callback должен быть доступен провайдеру по HTTPS. Ключи вводятся в карточке провайдера, а цены — в тарифах. Выключенный модуль или неподдерживаемая валюта не появляются как доступный способ оплаты. Подробные адреса callback и порядок проверки — в руководстве по платежам.

Бесплатный тариф с нулевой ценой выдаётся без платёжных модулей, в том числе при выключенной покупке и продлении в кабинете или Mini App. Платные тарифы при этом недоступны. Пробный доступ остаётся одноразовым; чтобы убрать его, отключите или скройте сам тариф.

## Проверка результата

Наличие ключа ещё не доказывает поступление платежа. Для нестандартного API нужен собственный Rust-модуль и пересборка. Автосписание требует поддержки конкретного провайдера.
