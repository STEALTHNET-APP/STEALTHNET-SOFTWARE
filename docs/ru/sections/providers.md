# Платёжки и валюты

Модуль создаёт счёт и подтверждает оплату. Доступны Stars, CryptoBot, ручная оплата и настраиваемый HTTP-модуль.

**Где открыть:** `#/providers` — Продажи.

## Порядок работы

1. Выберите валюту сервиса.
2. настройте ключи модуля.
3. включите нужные валюты.
4. задайте цены тарифов.
5. выполните тестовую покупку.

## Настройка провайдеров

Для Platega нужны Merchant ID и secret; для RollyPay — API key и signing secret; для ParityPay v2 — Shop ID и два секрета. Callback должен быть доступен провайдеру по HTTPS. Ключи вводятся в карточке провайдера, а цены — в тарифах. Выключенный модуль или неподдерживаемая валюта не появляются как доступный способ оплаты. Подробные адреса callback и порядок проверки — в руководстве по платежам.

## Проверка результата

Наличие ключа ещё не доказывает поступление платежа. Для нестандартного API нужен собственный Rust-модуль и пересборка. Автосписание требует поддержки конкретного провайдера.
